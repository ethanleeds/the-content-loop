# Life

The supply line. The agent can only turn into content what reaches this folder.

One file per week, or one line per thing. Anything counts:
- a PR, a new place, a hard conversation
- a book or video that changed how you think
- a build you shipped, a mistake you made, a decision and why
- a take you had in the shower

Write it the day it happens. One sentence beats a perfect note you never write.

Anything you never want turned into content goes in `vault/Private/`. The agent never reads it.
